# NUC-AFLtool
## Who am I
This is a tool for students of North University of China to make pictures of applications for leave quickly. This branch is a plugin for nonebot qq robot frame.

## Use
Add it as a plugin to the qq bot project written by nonebot frame. At this time, you should change the 34th line of the \_\_init\_\_.py file to make it point the picture file. Say "假条" to it, and follow its instructions to reply.
